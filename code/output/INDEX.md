# Experimental artifacts

Selected frozen experiment records, analysis sources, configurations, and verification inputs accompanying the MRV paper. Original study identifiers and source bytes are retained.

The archive paths preserve the `output/review/` hierarchy used by the analysis sources. `inventory.csv` records the path, byte length, and SHA-256 of every included file; `SHA256SUMS` identifies the bundles.

Bundles contain original analysis sources and selected frozen input/output records. Generated databases, build caches, and redundant expanded graph/order dumps are excluded; provenance manifests retain the original environment paths. Large archives are hosted in the repository release.
